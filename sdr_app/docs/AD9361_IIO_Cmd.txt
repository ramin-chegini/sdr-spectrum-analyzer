=========================================
AD9361 RX/TX Quick Command Reference
=========================================

=====================
RX1
=====================

Read Gain
cat /sys/bus/iio/devices/iio:device0/in_voltage0_hardwaregain

Set Gain (Manual mode only)
echo 30 > /sys/bus/iio/devices/iio:device0/in_voltage0_hardwaregain

Read Gain Control Mode
cat /sys/bus/iio/devices/iio:device0/in_voltage0_gain_control_mode

Set Manual Mode
echo manual > /sys/bus/iio/devices/iio:device0/in_voltage0_gain_control_mode

Read RSSI
cat /sys/bus/iio/devices/iio:device0/in_voltage0_rssi

Read RF Port
cat /sys/bus/iio/devices/iio:device0/in_voltage0_rf_port_select


=====================
RX2

Read RSSI

=====================
Notes
=====================

- RX Gain can only be changed after setting:
  gain_control_mode = manual

- RX1 and RX2 share:
  * RX LO
  * RF Bandwidth
  * Sample Rate

- TX1 and TX2 share:
  * TX LO
  * RF Bandwidth
  * Sample Rate
